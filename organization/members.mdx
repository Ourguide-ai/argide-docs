Everyone in your organization can use the dashboard. Roles decide who can change your agent's setup and who can only work with conversations and content.

## Roles

An organization has two roles: **Admin** and **Member**.

| Task | Admin | Member |
| ---- | :---: | :----: |
| View conversations, reports, and agent settings | ✓ | ✓ |
| Read, reply to, note, close, snooze, and star conversations | ✓ | ✓ |
| Upload, update, and remove knowledge base files, and crawl websites and help centers | ✓ | ✓ |
| View the member list | ✓ | ✓ |
| Save agent settings: **Agent** → **Identity**, **Instructions**, **Mode**, **Design**, **Suggestions**, and **Advanced**, plus the widget mode on **Deploy** → **Install** | ✓ | |
| Save **Agent** → **Escalation** | ✓ | |
| Change **Tools** → **In-Page Actions** and **Screen Context** | ✓ | |
| Create, edit, and delete workflows | ✓ | |
| Approve discovered routes and add or import routes on **Page Navigation** | ✓ | |
| Configure API tools on **Tools** → **Server Side** | ✓ | |
| Change **Settings** → **Email** and **Settings** → **Satisfaction** | ✓ | |
| Turn the Agent API on or off, and create or revoke Agent API keys | ✓ | |
| View `ARGIDE_AUTH_SECRET` on **Deploy** → **Backend Integration** | ✓ | |
| Create and edit products | ✓ | |
| Invite people, change roles, and remove members | ✓ | |

Members can still open these pages and see the current values, except `ARGIDE_AUTH_SECRET`, which only admins can view. Where they can't make a change, the control is disabled or the save fails, and some pages say "Only an org admin can change this setting."

## Invite someone

<Steps>
  <Step title="Open Members">
    In the sidebar, click **Settings**, then **Members** under **Account**.
  </Step>
  <Step title="Send the invite">
    Under **Invite a teammate**, enter their email, choose **Member** or **Admin**, and click **Send invite**.
  </Step>
</Steps>

They receive an email with a link to join. The invitation expires after 7 days.

- **Sending another invitation to the same email replaces the pending one.** The previous link stops working.
- **You can't invite someone who is already a member.**
- **If the email can't be delivered,** the invitation is still created. The link is copied to your clipboard, or shown on the page so you can copy and share it.
- **An organization can send up to 20 invitations an hour.**

## Accept an invitation

<Steps>
  <Step title="Open the link">
    Use the link in the invitation email.
  </Step>
  <Step title="Sign in">
    Sign in, or create an account, with the email address the invitation was sent to.
  </Step>
  <Step title="Join">
    Click **Accept invitation**. You land in that organization's dashboard.
  </Step>
</Steps>

The link only works for the invited email address. If you're signed in as someone else, sign out and open the link again.

Your email address must be verified. If you created the account with email and password, open the verification email before you accept. If an account with that email already exists, sign in with the method you used to create it.

## Manage access

Pending invitations appear under **Pending invitations** on the **Members** page. Click **Revoke** to cancel one. The link stops working immediately.

Use the role menu next to a person to switch them between **Member** and **Admin**. Click the remove button next to a person to take away their access. It ends immediately.

An organization must keep at least one admin. Promote another member before you remove or demote the last admin.
