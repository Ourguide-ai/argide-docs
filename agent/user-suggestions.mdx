---
title: "User suggestions"
description: "Give users one-click starting points and follow-up questions in the chat"
---

Suggestions are clickable chips in the chat. A user clicks one instead of typing, and the chip's message is sent to the agent as if they had typed it. Each chip can have follow-up chips that appear after the agent answers, so you can guide users down a short path.

Set them up in **Agent** → **Suggestions**. You need the Admin role in your organization to save changes.

## Add suggestions

<Steps>
  <Step title="Add a chip">
    Click **Add your first suggestion**, or **Add Suggestion** if you already have some.
  </Step>
  <Step title="Fill in the label and message">
    | Field | What it does |
    | ----- | ------------ |
    | **Button label** | The text on the chip. Required. |
    | **Message** | What gets sent to the agent when the chip is clicked. If you leave it empty, the label is sent. |
  </Step>
  <Step title="Add follow-ups (optional)">
    While a chip is open for editing, click **Add follow-up** to nest a chip under it. Follow-ups can have their own follow-ups.
  </Step>
  <Step title="Save">
    Click **Save Changes**. If any chip has an empty label, the save stops and highlights it. Add a label or remove the chip, then save again.
  </Step>
</Steps>

Click a saved chip's label to edit it again. The preview on the right shows your top-level chips in the widget.

## What users see

1. **Before the first message**, the top-level chips appear stacked above the message box, under the welcome message. On phones, the first five show with a **See all** link for the rest.
2. **When a user clicks a chip**, its message is sent. After the agent finishes replying, that chip's follow-ups appear. Follow-ups replace the previous set of chips.
3. **When a chip has no follow-ups, or the user types their own message**, the chips step back. The top-level set stays available behind a **Show suggestions** toggle, collapsed by default.
4. **When a new conversation starts**, the top-level chips appear again.

The agent knows which follow-ups the user is about to see, so it can shape its answer to lead into them without listing them itself.

## Show suggestions only to logged-in users

Turn on **Show suggestions only to logged-in users** to hide every chip from anonymous visitors. It's off by default.

"Logged in" means the widget has received a signed identity token for this page load: through the `identify` command. Passing a `user_id` with `update` alone doesn't count. See [User identification](/setup/user-identification).

The same rule hides [workflow](#workflows-as-suggestions) chips.

## When suggestions are hidden

Chips disappear from a conversation once a member of your team takes it over from the inbox. The agent no longer replies there, so a chip would send a message nothing answers. See [Escalation](/conversations/escalation).

## Workflows as suggestions

Each enabled, ready [workflow](/agent/workflows) with **Show as suggestion** on also appears as a chip, after your suggestion chips, labeled with the workflow's title. Clicking it doesn't send a message. It asks the user to confirm first, with **Run workflow** for an automated workflow or **Start walkthrough** for a guided one.

To keep a workflow off the chip row, clear **Show as suggestion** on it in **Tools** → **Workflows**. The workflow stays enabled, and the agent can still run it when a user asks for that task.

## Writing good suggestions

- **Keep labels short.** Two to four words keep chips on one line.
- **Put detail in the message.** The label is for the user; the message is for the agent. "Billing issue" can send "I have a question about a charge on my latest invoice."
- **Start from real questions.** Look at your most frequent conversations in the [inbox](/conversations/inbox) and turn them into chips.
- **Offer a few, not many.** Three or four top-level chips are easier to scan than ten.

| Use case | Label | Message |
| -------- | ----- | ------- |
| E-commerce | Track my order | What is the status of my most recent order? |
| E-commerce | Return an item | I want to start a return |
| SaaS | Get started | Walk me through the initial setup |
| SaaS | Upgrade plan | What plans are available and how do I upgrade? |
