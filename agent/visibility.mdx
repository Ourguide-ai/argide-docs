---
title: "Visibility"
description: "Control when the widget appears on your page"
---

By default the widget appears as soon as the script loads. To show it only at the right moment, such as after a user signs in, hide it on load with `data-visibility` and reveal it later with the `update` command.

## Hide the widget on load

Add `data-visibility="false"` to the script tag:

```html
<script>window.argide = window.argide || [];</script>
<script
  src="https://dashboard.argide.ai/argide-b2b.iife.js"
  data-product-id="YOUR_PRODUCT_ID"
  data-api-url="https://api.argide.ai"
  data-visibility="false"
></script>
```

Nothing renders: no launcher bubble, no chat panel, no conversation. The script still loads, so the widget appears as soon as you reveal it, and commands such as `identify` still run while it's hidden.

Only the exact value `"false"` hides the widget. Any other value, or no attribute at all, shows it, so existing embed code keeps working unchanged.

You can set the same flag in `window.ArgideSettings` before the script loads:

```html
<script>
  window.ArgideSettings = { visibility: false };
</script>
```

## Show and hide

Pass `visibility` to the `update` command:

```javascript
window.argide('update', { visibility: true });

window.argide('update', { visibility: false });
```

This is the only way to change visibility. There are no separate show or hide commands.

Hiding the widget closes the chat panel and removes the bubble from the page. The conversation is kept, so it's still there when you show the widget again.

The first line of the embed code, `window.argide = window.argide || [];`, lets you call the widget before the script has finished loading. If your code may run first, queue the command instead:

```javascript
window.argide.push(['update', { visibility: true }]);
```

The command runs as soon as the widget is ready.

<Info>
  `visibility` stays in the browser. It's never sent to Argide and never appears on a conversation.
</Info>

## Show the widget only to signed-in users

Hide the widget on the script tag, then reveal it after login. Send the user's attributes in the same `update` call so the agent knows who it's talking to from the first message:

```javascript
window.argide('update', {
  visibility: true,
  user_id: 'usr_8241',
  name: 'Ada Lovelace',
  email: 'ada@example.com',
});
```

On logout, hide the widget and clear the session:

```javascript
window.argide('update', { visibility: false });
window.argide('resetAndClearSession');
```

See [User identification](/setup/user-identification) for the attributes you can pass.

## Reference

| Setting | Where | Values | Default |
| ------- | ----- | ------ | ------- |
| `data-visibility` | Script tag attribute | `"false"` hides the widget on load | Visible |
| `visibility` | `window.ArgideSettings`, or the `update` command | `true` or `false` | `true` |
