`@ourguide-ai/agent` is published to **GitHub Packages** as a private package, so every install needs the install token Argide gives you. Complete these three steps once per project, and set the token in every environment that builds your app.

<Note>
  Already have your token configured? Skip to the [quickstart](/agent-sdk/quickstart).
</Note>

## 1. Get your install token

Email [support@argide.ai](mailto:support@argide.ai) and we send you an install token through a one-time link. You don't need a GitHub account.

## 2. Point the scope at GitHub Packages

Add an `.npmrc` to your project root:

```bash .npmrc
@ourguide-ai:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${ARGIDE_NPM_TOKEN}
```

This routes only the `@ourguide-ai` scope to GitHub Packages. Every other dependency still comes from the public npm registry.

npm, pnpm, and Yarn Classic read `.npmrc`. Yarn Berry reads `.yarnrc.yml` instead:

```yaml .yarnrc.yml
npmScopes:
  ourguide-ai:
    npmRegistryServer: "https://npm.pkg.github.com"
    npmAuthToken: "${ARGIDE_NPM_TOKEN}"
```

## 3. Set the token wherever you install

The `${ARGIDE_NPM_TOKEN}` above is expanded from the environment at install time, so set it everywhere an install runs — your shell, your CI jobs, your Docker builds, and any platform that builds the app for you (Vercel, Netlify, Amplify, and similar).

<CodeGroup>

```bash npm
export ARGIDE_NPM_TOKEN=<your token>
npm install @ourguide-ai/agent
```

```bash pnpm
export ARGIDE_NPM_TOKEN=<your token>
pnpm add @ourguide-ai/agent
```

```bash yarn
export ARGIDE_NPM_TOKEN=<your token>
yarn add @ourguide-ai/agent
```

</CodeGroup>

<Warning>
  Keep the token out of source control. Because `.npmrc` references `${ARGIDE_NPM_TOKEN}` rather than the token itself, the file stays safe to commit — but if you paste a literal token in, add `.npmrc` to your `.gitignore`.
</Warning>

## Troubleshooting

| Symptom | Cause |
| ------- | ----- |
| `401`, `authentication token not provided`, or `User cannot be authenticated with the token provided` | `ARGIDE_NPM_TOKEN` is unset, empty, or mistyped in the environment running the install, or the token was revoked. |
| `Failed to replace env in config` or `Environment variable not found` | `ARGIDE_NPM_TOKEN` is unset (pnpm, Yarn). |
| `404` from `registry.npmjs.org` or `registry.yarnpkg.com` | The `@ourguide-ai` scope isn't routed to GitHub Packages. pnpm ignores the whole `.npmrc` when `ARGIDE_NPM_TOKEN` is unset, and Yarn Berry reads `.yarnrc.yml`, not `.npmrc`. |
| `403` or `404` from `npm.pkg.github.com` | The token can't read the package. Contact [support@argide.ai](mailto:support@argide.ai) for a new one. |
| Works locally, fails in CI | The token is exported in your shell but not in the CI environment or Docker build. |
