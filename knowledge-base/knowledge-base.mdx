The knowledge base is what your agent knows about your product. You manage it on one page in the dashboard: **Knowledge Base**.

The page has three sections. Each one feeds a different part of the agent.

| Section | What you add | What it feeds |
| --- | --- | --- |
| **Website** | Your web app or site, crawled | [Page navigation](/agent/page-navigation) routes, so the agent can take users to the right page |
| **Help center & docs** | Your help center or documentation site, crawled | Answers to user questions |
| **Files** | PDFs, Word and Excel documents, text, Markdown, CSV and JSON files | Answers to user questions |

<Note>
  The **Website** crawl doesn't add page content to the knowledge base. It only builds the list of routes the agent uses to navigate. To make your help articles answerable, crawl them under **Help center & docs**.
</Note>

## How the agent uses knowledge

1. A user sends a message.
2. Argide searches your **Help center & docs** and **Files** content for the passages most relevant to that message.
3. The agent answers from those passages.

The agent grounds its answers in your content, not its general knowledge:

- **No relevant passage.** The agent tells the user the knowledge base doesn't cover the question instead of guessing.
- **Empty knowledge base.** The agent tells the user that no product-specific information is available yet. It can still use its tools and actions.
- **Workflow in progress.** While the agent is running a [workflow](/agent/workflows), it skips the search and focuses on the task.

To see what the agent retrieved for a reply, open the conversation in [Conversations](/conversations/inbox) and select the **RAG** tab.

## Keep it fresh

Nothing re-crawls or re-processes on a schedule. When your product or docs change, update the knowledge base yourself:

- **Crawled sites.** Click **Re-crawl** next to the site. A website re-crawl sends any new or changed routes to review before they go live.
- **Files.** Click **Update** next to the file and pick the new version. It replaces the old content in place.
- **Outdated sources.** Remove a site or file you no longer want the agent to use.
