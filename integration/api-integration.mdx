API integration is optional. Your agent already answers from your knowledge base, navigates your app, and works in the page without it. Connecting your API adds one thing: the agent can call your REST endpoints directly, from Argide's servers, to fetch data or make changes for the user.

## When you need it

Connect your API when the agent needs something it can't get from the page:

- **Data that isn't on screen.** Order status, invoice history, usage limits, account details.
- **Actions that are faster through the API.** Cancel a subscription, issue a refund, create a support ticket, update a setting.
- **Per-user answers.** "Where's *my* order?" — with [JWT Forward](/integration/identity-verification), each call runs as the signed-in user.

If the agent only needs to explain your product or guide users through the UI, skip this section.

## How it works

1. **You describe your API.** You upload an OpenAPI 3.x spec. Each operation in it becomes a tool the agent can call.
2. **You choose what the agent can call.** New tools start disabled. You turn on only the endpoints you want the agent to use.
3. **The agent picks a tool.** When a user's request matches an enabled endpoint, the agent fills in its parameters from the conversation.
4. **Argide calls your API.** Argide's servers send the request to your **API Base URL**, with the authentication you configured.
5. **The agent answers.** It reads the response and replies to the user. While the call runs, the widget shows the endpoint's `summary` as the action name.

<Note>
  Argide's servers make the request, not the user's browser. Your **API Base URL** must be reachable from the internet, and API calls don't show the Allow/Deny approval card that [in-page actions](/agent/in-page-actions) can. Enable only endpoints you're comfortable with the agent calling on its own.
</Note>

## Set it up

All of this lives on one dashboard page: **Tools** → **Server Side**. You need the admin role to change it.

<Steps>
  <Step title="Save your API configuration">
    Enter your **API Base URL**, choose an **Authentication** type, and click **Save Configuration**. You must save this before you can upload a spec.
  </Step>
  <Step title="Upload your OpenAPI spec">
    Drop in a JSON or YAML OpenAPI 3.x file. Argide generates one tool per operation.
  </Step>
  <Step title="Enable the tools">
    Under **Generated Tools**, switch on the endpoints the agent may call, then click **Save Changes**.
  </Step>
  <Step title="Set up identity verification (JWT Forward only)">
    If your API acts on behalf of the signed-in user, have your backend mint a token for each user and pass it to the widget.
  </Step>
</Steps>

The same enabled tools are also available to tasks you run through the [Agent SDK](/agent-sdk/overview).
