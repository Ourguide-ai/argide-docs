Argide is an AI agent you add to your website or web app with one script tag. It lives in a chat panel on your pages, and it does more than answer questions: it can move around your app and work in it for the user, in their own browser session.

## What the agent can do

| Capability | What it means for your users |
| --- | --- |
| **Answer from your knowledge base** | Replies are grounded in your help center, docs, and uploaded files. |
| **Navigate your app** | "Where do I change my billing email?" takes the user straight to the right page. |
| **Run workflows** | Recorded multi-step tasks run for the user, or the agent walks them through each step. |
| **Act on the page** | The agent clicks buttons, fills forms, and selects options, after the user approves. |
| **Call your APIs** | The agent calls endpoints from your OpenAPI spec, as the signed-in user if you choose. |
| **Hand over to your team** | When the user asks for a person, the agent can pass the conversation to your team. |

You configure all of this in the [dashboard](https://dashboard.argide.ai/dashboard). Every conversation lands in **Conversations**, where your team can read it, reply, and step in.

## Ways to add Argide

| | Chat widget | Copilot | Agent SDK |
| --- | --- | --- | --- |
| **What users see** | A chat bubble in the bottom corner that opens a panel | A full-height sidebar beside your app, on the left or right | No Argide UI. Your own assistant stays in front. |
| **How you add it** | Script tag | Same script tag, different mode | npm package plus one server endpoint |
| **Best for** | Marketing sites, support on public pages, mobile-first apps | In-product assistants, dashboards, power-user tools | Products that already have a chatbot and want Argide to carry out tasks |

The widget and the copilot are two modes of the same script tag. You switch between them in the dashboard without touching your code. On screens 768px wide or narrower, the copilot falls back to the widget layout.

The [Agent SDK](/agent-sdk/overview) is a separate, headless option: your own chatbot delegates a goal, and an Argide agent completes it in the user's tab.
